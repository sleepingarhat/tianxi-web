本文件為現行藍圖，取代 2026-10-07 三產品架構。足球、六合彩暫時封存，不刪歷史帳與源碼，不再作現行待辦。

## 產品方向與免費路線
- 深耕香港本地賽馬：沙田、跑馬地；模型主指標為四揀平均命中匹數，目標 3／4，市場熱門 2.31 為對照，唔宣稱已達標。
- 現阶段所有賽馬功能免費；登記會員累積 500 人後才安排 iOS App 與收費。歷史成績、公開對帳永久免費，負數如實展示。
- 現階段限時免費享有等同Pro嘅全站已有功能，唔係已開通付費訂閱。首500名註冊會員於開放收費閘之日起免費享一年（52週）Pro，總值HK$4,056；首頁醒目展示並附現在註冊入口。將來Pro為HK$78／星期自動續訂，暫時唯一資格、冇免費試用；付款接駁未完成。
- 品牌保留翠綠／金色喜字與馬，移除足球及六合彩球；頁頂、favicon、手機主畫面圖示統一。

## 前台
首頁天喜賽馬 → 賽馬儀表板、選馬、排位／賠率、賽果、預測與賽果、六彩池策略盈虧、公開戰績、百科、回測、引擎健康。
底部導航：首頁／選馬／排位／引擎。足球與六合彩舊頁返回賽馬首頁，不再載入產品資料。

## 後端設計
排位及賽前 as-of 資料 → Elo／LightGBM 排序 → 首場前 90 分鐘鎖全日四揀與第五選 → 官方賽果及派彩 → 只重算對帳，不改凍結。
四個單場彩池與孖T／三T沿用原計算，不因產品收斂更改成本、派彩、模型、指紋或鎖定規則。
足球／六合彩 API 停用回 410；定時工作及鏡像停止，歷史表保留但不再公開讀取。

## 監控端
沿用側欄、AdminHead／Panel／Kpi／DataTable，保留賽馬總覽、引擎健康、資料新鮮度、預測鎖定、賽馬模型版本、六彩池盈虧、會員、賽馬日誌、設定、運維工具。取消足球逐季匯出、陣容、雙引擎與六合彩監控，不把已封存任務當故障。
